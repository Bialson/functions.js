# Functions.JS
New version of program about functions of 2 variables written in Python

**Program jest odpowiedzią na poniższe założenia**
>- Wizualizacja funkcji matematycznych w 2D i 3D
>- Interakcja użytkownika z interfejsem graficznym (obracanie wykresu, odczytywanie wartości funkcji, wpisywanie własnych wzorów)
>- Obszerna personalizacja środowiska
>- Możliwość eksportu modeli 3D w formacie dla drukarek 3D oraz w formacie graficznym (.PDF, .PNG, .SVG, etc...)
>- Symulacje przebiegu zjawisk fizycznych (*po zrealizowaniu powyższych*)
>- Analiza matematyczna danej funkcji
